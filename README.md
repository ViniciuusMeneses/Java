# Java

Meus estudos de Java: exercícios de Programação 2 no CESUPA e de um curso rápido de Java. Cada exercício fica numa pasta própria, com um `Main.java`.

## Como rodar

Use o Java 25 ou mais novo. Alguns exercícios usam `void main()` sem `static` e a classe `IO`, que entraram na linguagem no Java 25.

```bash
cd curso-rapido/12-conta-bancaria
java Main.java
```
